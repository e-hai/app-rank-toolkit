实现方式：

- toolkit / novel：workflow 在部署前写入 `site/{key}.txt`，部署后读 sitemap 批量 POST `https://api.indexnow.org/indexnow`
- apprank：仓库原本已有 IndexNow（`src/incremental.py` 只提交变化 URL，`generate.py` 写 key 文件），本轮只补 secret，首次运行即生效

踩坑记录：

1. **先部署再提交**。首次在部署前提交会得到 `SiteVerificationNotCompleted`，因为 key 文件还没上线。apprank 的生成器在构建阶段提交，所以首次必失败一次，属预期。
2. **批量过大触发限流**。同一 host 连续提交过多 URL 会返回 `UserForbiddedToAccessSite`，与 URL 是否 200 无关（539 条逐条 HEAD 全是 200）。稳妥做法是每次 ≤50 条、间隔 1–2 秒，或只提交变化 URL。
3. **IndexNow 不含 Google**。Bing / Yandex / Naver / Seznam 参与，Google 仍靠 sitemap + GSC。
